# Guardrail Wallet v0.1.0-alpha.1

Guardrail Wallet is a self-hosted payment firewall for AI agents where the owner sees all risky requests before funds are moved.

## What ships in this early-access launch

- Agent request flow: `POST /v1/payments/request`, with deterministic policy decision and owner review for flagged requests.
- Request lifecycle: every payment goes through a policy gate, and owner approvals are required when policy asks for them (`pending_approval` → `approved`/`rejected`).
- A household example is now the primary launch story: the agent asks, policy checks the context, and the owner approves or rejects.

## Safety and limitations

The public demo is for demonstration only and uses `EXECUTOR=stub`.  
No real money moves in public demo requests, and request outcomes are simulated.

- TON remains experimental and is currently a pluggable executor path.
- The TON guardrail contract is unaudited at this stage.
- Do not place large mainnet balances behind the software.
